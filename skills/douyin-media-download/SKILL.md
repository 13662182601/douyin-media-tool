# 抖音视频与完整音轨下载

## 执行边界

- 将明确的下载请求或连续下载对话中的分享链接视为下载目标；意图不明确时先询问。
- 仅获取可公开访问的作品。不绕过身份验证、访问控制、付费限制或验证码，不索取个人 Cookie。
- 不把用户下载请求解释为拥有版权、允许商用或允许发布。提醒遵守平台规则和作品使用权要求，不代填权利声明。
- 默认仅下载视频并保留完整原音轨。仅在用户明确要求时添加 `--audio` 提取完整混合音轨，不执行人声分离。
- 使用原始下载分辨率与编码，不伪造高清、最高画质、无水印或原创声明。

## 准备环境

1. 定位本 Skill 的绝对目录，使用随包提供的 `scripts/download.py`，不依赖工作台源目录。
2. 检查 Python 3.10+ 及 FFmpeg。优先使用 PATH 中的 FFmpeg，必要时设置 `MEDIA_FFMPEG` 为已验证可执行文件的绝对路径；支持已安装的可选 `imageio_ffmpeg`，不自动安装系统软件。
3. 选择当前工作区的 `downloads` 或用户指定目录。先检查父目录，不扫描无关个人目录，不覆盖已有媒体。

## 下载

将完整分享文本作为一个参数传入，保留原短链大小写。使用参数数组调用子进程；使用 shell 时妥善引用文本，禁止直接拼接未转义内容执行。

```bash
python3 "<本Skill绝对目录>/scripts/download.py" "<抖音分享文本或HTTPS链接>" --output-dir "<交付目录绝对路径>"
```

需要完整混合音轨时执行：

```bash
python3 "<本Skill绝对目录>/scripts/download.py" "<抖音分享文本或HTTPS链接>" --output-dir "<交付目录绝对路径>" --audio
```

运行较长下载时使用受管理的后台任务，完成后读取退出状态与 JSON 输出，不轮询睡眠，不将部分文件当成功文件。

## 校验与失败处理

按需读取 `references/api_reference.md` 中的 JSON 字段和故障处理说明。

- 以退出码为零且返回的文件真实存在为交付前提，读取脚本输出中的真实元数据。
- 依赖下载器执行白名单、DNS公网绑定、大小时长限制、内容长度和 FFmpeg 完整解码校验。保留安全检查，不扩大域名范围规避报错。
- 允许脚本对源站提供的备用 CDN 有限切换，不重复无限重试。
- 源站无可用视频、接口变更、超时、超过大小/时长限制时说明具体错误。不虚构下载结果，不要求用户执行无关部署操作。
- 不交付 `.part` 文件；不修改已有下载文件；不自动删除用户媒体。

## 交付

用文件交付入口展示已校验的 MP4；请求音轨时一并交付 M4A。简要报告真实时长、分辨率、大小及原音轨是否存在。无音轨则明确说明，未目视检查则不宣称画面观感验收通过。不主动上传云端、发布网站或加入曲库。
