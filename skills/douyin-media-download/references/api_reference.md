# 下载器输出与故障处理

调用 `scripts/download.py`，成功退出码为 0，失败为 1，用户中断为 130。`--help` 输出普通帮助文字，其他执行结果输出单行 JSON。

成功字段：`ok`、`videoId`、`title`、`sourceUrl`、`videoPath`、`audioPath`、`duration`、`hasAudio`、`audioExtracted`、`bytes`。`audioPath` 未提取时为 null，`bytes` 为视频字节数，`duration` 为媒体容器的秒数。只报告实际返回的字段，不从作品描述推测画面内容。

失败字段：`ok: false` 与 `error`。源站无法提供地址时，不保证作品已删除；也可能为图集、访问受限或源站接口变化。

下载器将原始媒体写入本任务临时目录，完整解码验证后，以无覆盖的原子文件创建方式发布作品ID命名的 MP4。同名文件存在时添加数字后缀。仅清理本任务临时文件，不清理历史下载。硬链接不受文件系统支持时允许安全失败，不降级为覆盖写入。

默认最大视频 200 MiB、最长 1800 秒，每条允许的 CDN 线路独立超时，最多三条；只使用详情响应提供且通过白名单的播放地址。源站接口非稳定开放接口，不能承诺长期可用。

可选 M4A 为原 AAC 混合音轨的无损封装，不是分离出的纯背景音乐。无声视频可正常下载；请求音轨而原视频无 AAC 音轨时应明确失败。

FFmpeg 为独立外部软件，使用者应遵守其发行版本的许可证。工具不分发 FFmpeg，不依赖浏览器、Docker、个人Cookie或付费解析服务。
